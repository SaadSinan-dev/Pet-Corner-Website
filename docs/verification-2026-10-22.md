## دليل التدفق المتكامل

أُنشئت فئة ومنتج من لوحة الإدارة عبر طلبات حقيقية، ورُفعت صورتان وأعيد ترتيبهما. سعر الوحدة 45,678، المخزون 9. شراء وحدتين حفظ المجموع الفرعي 91,356 والتوصيل والإجمالي null. قُطعت الاستجابة بعد حفظ الخادم، ثم أُعيدت المحاولة بنفس المفتاح: طلب واحد فقط ومخزون 7. ظهر الطلب في الإدارة؛ حفظ تسعير توصيل 12,000 أعطى إجماليًا 103,356 وحالة CONFIRMED وسجل تعديل. تحديث الإيصال عرض القيم الجديدة.

لم ينطلق أي طلب شبكة إلى WhatsApp تلقائيًا؛ الرسالة المجهزة تحتوي بيانات الطلب والتوصيل المعلّق أو القيم المؤكدة. طلب الإيصال برقم الطلب وحده، وعمليات الإدارة بلا مصادقة، رُفضت. ملفات الدليل المحفوظة تستبعد رمز الإيصال وكلمة مرور المدير.

اختبارات إضافية تغطي المخزون المتزامن، منع التكرار، rollback عند فشل عنصر، الإلغاء وإعادة المخزون مرة واحدة، استعادة regionId القديم بعد تعطيل checkout، رفع الصور غير الصالحة، القيود المالية في PostgreSQL، حماية الحساب المعطّل، وخفاء demo في الإنتاج.

## المشاكل التي كُشفت وأُصلحت أثناء التحقق

1. عنوان جدول مخفي لقارئ الشاشة كان يسبب overflow على الهاتف في الإدارة: ثُبّت نطاقه داخل `.table-scroll` بـ`position: relative`. أعيد اختبار الصفحة عند 320 بكسل ثم المصفوفة كاملة.
2. صفحة 404 الإدارية كانت بلا h1: أصبحت تحتوي عنوان صفحة رئيسيًا مناسبًا.
3. عولجت سباقات في أداة اختبار استعادة الاستجابة ومسار main المؤجل، وأصبح الاختبار ينتظر إتمام طلب الشبكة قبل إزالة اعتراضه، وينتظر تحديث رابط البحث قبل الترتيب.
4. وُحدت منافذ أمثلة التطوير على 5174 للمتجر و5175 للإدارة. وُضح ترتيب الكتالوج باسم «ترتيب المتجر» لأنه يحترم ترتيب الإدارة.
5. الشعار الداكن يُعرض فوق مساحة فاتحة، دون فلتر يغيّر ألوان الأصل. الملفات الأصلية في المتجر والإدارة تطابق SHA-256 للملف المرفق: `d23f8cd36c271ab4c3bf08d301e894ee3b883c9bb4ede992b52f8033b5b68564`، 500×500 RGBA.

## حفظ البيانات وحدود التحقق

Migration إضافية أبقت الطلبات التاريخية وتكاليفها دون تحويلها إلى null. فحص الترقية سجل 19 منتجًا و6 طلبات قديمة محفوظة، مع تحديد 14 منتج seed معروفًا فقط كـdemo؛ خمسة سجلات اختبارات سابقة بقيت معطّلة. لا reset أو حذف لسجلات المتجر. اختبارات API استخدمت قاعدة `_test` منفصلة، والمتصفح أنشأ قواعد فريدة ومنافذ منفصلة. تحتفظ قواعد المتصفح ببياناتها للمراجعة ولا تُحذف تلقائيًا.

أُجريت مراجعة مصدر داخل المهمة لمسارات المصادقة والتسعير والمخزون واستعادة الطلب والإعدادات والتخزين. محاولة المراجعة النهائية عبر وكيل مستقل لم تكتمل بسبب حد الاستخدام؛ لا يُدّعى نجاح مراجعة مستقلة لهذه الترقية.

Docker Engine غير متاح؛ لا ادعاء بتشغيل Compose/Nginx/Caddy أو إصدار شهادة أو نجاح backup/restore فعلي. النسخة الاحتياطية سكربت جاهز فُحصت صيغته فقط. قبل الإطلاق: تهيئة المضيف وDNS وHTTPS، اختبار health عبر النطاقين، تجربة النسخ والاستعادة في بيئة منفصلة، ضبط المراقبة وحدود الطلبات بحسب proxy، إدخال بيانات المنتجات والسياسات المعتمدة ورقم WhatsApp، وإنشاء المدير. لا بوابة دفع إلكتروني أو WhatsApp Business API موصولة.
